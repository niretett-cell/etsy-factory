## Så aktiverar du hemsidan (1 minut)
1. Gå till https://github.com/niretett-cell/etsy-factory/settings/pages
2. Under **Source** välj **Deploy from a branch**
3. Branch: **main** → folder **/ (root)** → Save
4. Vänta 30–60 sekunder, sedan fungerar länken ovan.
